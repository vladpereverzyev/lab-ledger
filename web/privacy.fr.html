Lab Ledger Dental - politique de confidentialité

Dernière mise à jour : 1er octobre 2026

Lab Ledger Dental est une application de bureau pour les laboratoires dentaires, créée par Vladyslav Pereverzyev. Cette page explique ce que deviennent les données que vous y saisissez. En bref : elles restent sur votre ordinateur. Je ne les collecte pas, je ne les vois pas et personne d'autre ne les reçoit par l'application.

Ce que l'application enregistre

Tout ce que vous saisissez dans Lab Ledger Dental est enregistré dans un fichier sur votre propre ordinateur : travaux, patients, cabinets, expéditions, matériaux, coûts, impôts, informations du laboratoire et utilisateurs de l'application. L'application indique où se trouve ce fichier dans Réglages.

  • Il n'y a aucun compte à créer ni aucun serveur auquel se connecter.
  • Les mots de passe des utilisateurs ne sont jamais enregistrés en clair. Seul un hachage PBKDF2-SHA256 salé est conservé, dans le même fichier local.
  • Les sauvegardes, les exports Excel et la copie Excel automatique sont écrits uniquement là où vous choisissez de les enregistrer.

Ce que l'application envoie

Lab Ledger Dental n'a ni statistiques d'utilisation, ni suivi, ni publicité, ni rapports d'erreur. Vos données ne sont jamais envoyées nulle part.

  • Versions Microsoft Store et Mac App Store : l'application ne fait aucune requête réseau d'elle-même. Les mises à jour passent par la boutique.
  • Version téléchargée sur GitHub : si la recherche de mises à jour est activée (vous pouvez la désactiver dans Réglages), l'application demande à GitHub au plus une fois par jour quelle est la dernière version. Cette requête ne contient que le nom de l'application et son numéro de version. GitHub voit votre adresse IP, comme pour toute visite d'un site, et la traite selon le GitHub Privacy Statement. Une mise à jour n'est téléchargée que lorsque vous appuyez sur le bouton.
  • Les liens de l'application, comme la licence ou le site de l'auteur, s'ouvrent dans votre navigateur seulement quand vous cliquez dessus.

Données des patients

Lab Ledger Dental peut contenir des données personnelles de patients et de cabinets. Comme elles ne quittent jamais votre ordinateur, le laboratoire qui utilise l'application reste responsable du traitement de ces données et doit les conserver comme la loi l'exige, par exemple le RGPD. Protégez l'ordinateur et ses sauvegardes comme tout autre dossier patient et donnez à chaque personne du laboratoire son propre utilisateur avec seulement les droits dont elle a besoin.

Démo dans le navigateur

La démo en ligne fonctionne entièrement dans votre navigateur avec des données d'exemple. Ce que vous y modifiez reste uniquement dans le stockage de votre navigateur. La page est hébergée sur GitHub Pages, qui peut enregistrer les visites selon le GitHub Privacy Statement.

Enfants

Lab Ledger Dental est un outil de travail pour les laboratoires dentaires et n'est pas destiné aux enfants.

Modifications

Si un jour l'application traite les données autrement, cette page sera mise à jour avant la sortie de cette version, avec une nouvelle date en haut.

Contact

Pour toute question sur la confidentialité, ouvrez une issue sur GitHub ou écrivez-moi via vladpereverzyev.com.

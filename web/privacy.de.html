Lab Ledger Dental - Datenschutzerklärung

Zuletzt aktualisiert am 1. Oktober 2026

Lab Ledger Dental ist eine Desktop-App für Dentallabore, entwickelt von Vladyslav Pereverzyev. Diese Seite erklärt, was mit den Daten passiert, die du eingibst. Kurz gesagt bleiben sie auf deinem Computer. Ich sammle sie nicht, ich sehe sie nicht und niemand sonst bekommt sie über die App.

Was die App speichert

Alles, was du in Lab Ledger Dental eingibst, wird in einer Datei auf deinem eigenen Computer gespeichert. Dazu gehören Arbeiten, Patienten, Praxen, Versand, Materialien, Kosten, Steuern, Labordaten und die Benutzer der App. Wo diese Datei liegt, zeigt die App unter Einstellungen.

  • Es gibt kein Konto zu erstellen und keinen Server, bei dem man sich anmeldet.
  • Die Passwörter der Benutzer werden nie als Text gespeichert. Gespeichert wird nur ein gesalzener PBKDF2-SHA256-Hash, in derselben lokalen Datei.
  • Sicherungen, Excel-Exporte und die automatische Excel-Kopie werden nur dort geschrieben, wo du sie speichern willst.

Was die App sendet

Lab Ledger Dental hat keine Nutzungsstatistik, kein Tracking, keine Werbung und keine Fehlerberichte. Deine Daten werden nie irgendwohin hochgeladen.

  • Versionen aus dem Microsoft Store und dem Mac App Store. Die App stellt von sich aus keine Netzwerkanfragen. Updates kommen über den jeweiligen Store.
  • Von GitHub heruntergeladene Version. Wenn die Update-Prüfung eingeschaltet ist (du kannst sie unter Einstellungen ausschalten), fragt die App höchstens einmal am Tag bei GitHub nach der neuesten Version. Diese Anfrage enthält nur den Namen der App und die Versionsnummer. GitHub sieht deine IP-Adresse, wie bei jedem Besuch einer Website, und behandelt sie nach dem GitHub Privacy Statement. Ein Update wird nur heruntergeladen, wenn du auf den Button drückst.
  • Links in der App, etwa zur Lizenz oder zur Website des Autors, öffnen sich nur dann im Browser, wenn du sie anklickst.

Patientendaten

Lab Ledger Dental kann personenbezogene Daten von Patienten und Praxen enthalten. Da sie deinen Computer nie verlassen, bleibt das Labor, das die App nutzt, der Verantwortliche für diese Daten und muss sie so aufbewahren, wie es das Gesetz verlangt, zum Beispiel die DSGVO. Schütze den Computer und seine Sicherungen wie jede andere Patientenakte und gib jeder Person im Labor einen eigenen Benutzer mit nur den Rechten, die sie braucht.

Demo im Browser

Die Online-Demo läuft vollständig in deinem Browser mit Beispieldaten. Was du dort änderst, bleibt nur im Speicher deines Browsers. Die Seite liegt auf GitHub Pages, das Besuche nach dem GitHub Privacy Statement protokollieren kann.

Kinder

Lab Ledger Dental ist ein Arbeitswerkzeug für Dentallabore und nicht für Kinder gedacht.

Änderungen

Sollte die App Daten einmal anders behandeln, wird diese Seite vor dem Erscheinen dieser Version aktualisiert, mit einem neuen Datum oben.
